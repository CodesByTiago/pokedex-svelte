# Product Roadmap

Este documento registra a estratégia do produto: iniciativas, objetivos e prioridades. O [PRD](./prd.md) registra o escopo e os requisitos atuais.

O planejamento da entrega fica a cargo do Product Owner (skill `po-feature`), que lê este roadmap e cria as sprints e os épicos em [epics/](./epics/). O roadmap só linka as sprints; o status dos épicos vive no README de cada sprint e no documento do épico.
